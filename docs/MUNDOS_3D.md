# Mundos y escenarios 3D (rutas experimentales)

La pestaña Mundos 3D prepara comandos y adaptadores aislados para repositorios externos. **No se ha hecho inferencia real con GPU**, instalado estos entornos ni verificado todas sus dependencias; están preparados para depuración. SHARP y ambas versiones de WorldMirror pueden prepararse desde Studio; para rutas manuales se configuran variables en el entorno del servidor antes de arrancar, nunca ejecutables arbitrarios desde la API. Cada motor requiere su propia instalación de Python y GPU NVIDIA con medición de VRAM. Los repositorios y ejecutables son código externo de confianza, con los permisos del servidor. Acepta las licencias y acceso de cada modelo en sus páginas oficiales; para modelos gated, configura el token de Hugging Face en el apartado seguro de Studio. Algunos runtimes descargan grandes pesos, encoders o componentes adicionales en la primera ejecución. El indicador de rutas comprueba solo archivos básicos, no capacidad real de ejecutar el modelo.

Las variables `_REPO` son la raíz de los clones y `_PYTHON` el ejecutable Python del entorno correspondiente. Las versiones de código inspeccionadas son SHARP `aed6527`, WorldGen `7ce7b27`, Mirror `c61300e`, HY-World 2.0 `df9988e`, wrapper 1.0 `3e45e6e`, WorldSplat `075853f`. Seguir sus instrucciones de instalación originales y compilar extensiones de CUDA con versiones compatibles. SHARP y ambas versiones de WorldMirror disponen de preparación automática experimental; el resto requiere instalación manual.

El pipeline completo de HY-World 2.0 recibe una imagen panorámica 360°, no genera por sí mismo el panorama desde texto; la salida incluye los archivos de entrenamiento seleccionados y mapas/cámaras disponibles. El vLLM configurado recibe datos de la escena: usa solo un servicio de confianza. En Mirror se seleccionan hasta 17 imágenes de la misma escena; los ZIP incluyen salidas compatibles producidas por el upstream (PLY, PNG, JSON, NPY), no se garantiza que todas existan. En el resto de rutas una sola imagen como máximo. Los modelos pueden inferir zonas no observadas y los pases de profundidad/normales son estimaciones. Para combinar objetos, cámara e iluminación utiliza Blender u otro editor externo; los controles de imagen pueden mejorar coherencia, **no garantizan posiciones exactas**. La interfaz no incluye un visor 3D interactivo. Exportación general ZIP incluye los resultados de Mundos.

### Preparación automática experimental

En Mundos 3D, selecciona **Apple SHARP** o **WorldMirror**, revisa sus licencias y pulsa **Preparar motor seleccionado**; también se preparan al generar si aún falta el entorno. Se crea un entorno aislado en `DATA_ROOT/runtimes/scene3d` usando `python3.13` ya instalado (recomendación upstream); el checkpoint se descargará al generar, no durante la preparación. El monitor permite seguir o cancelar el trabajo. Se requiere espacio, compilador y acceso a las fuentes/dependencias; no se instalan paquetes del sistema. El éxito comprueba imports, no una inferencia GPU. Las rutas configuradas manualmente tienen prioridad.

WorldMirror original (Python 3.10) y WorldMirror 2.0 (Python 3.11) pueden prepararse automáticamente con CUDA compatible, gsplat y FlashAttention; requiere compilación y mucho espacio. La preparación automática de **WorldGen, HY-World 2.0 completo, HunyuanWorld 1.0 y WorldSplat** aún no está implementada. Sus adaptadores siguen requiriendo la instalación manual anterior; en particular HY-World 2.0 completo necesita además un servicio vLLM externo. La interfaz no los presenta como preparados automáticamente.
